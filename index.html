Hackathon Project · Multi-Agent RAG System · EPITA 2026

ER-Assistant - A chatbot for First Aid & Emergency Medicine

Built an AI assistant that answers questions about first aid, CPR, and emergency medicine using the Red Cross First Aid/CPR/AED Comprehensive Guide as its primary knowledge source. Developed as part of a 4-person team at EPITA.

The system combines RAG and multi-agent verification to make answers more reliable and traceable. Relevant passages are retrieved from the guide and highlighted directly on the original PDF pages, allowing users to see where each answer comes from.

Key Contributions

  • Developed the RAG pipeline using PyMuPDF, OpenAI embeddings, and FAISS for document processing and semantic retrieval.
  • Designed a multi-agent verification pipeline with an Internal Researcher, External Fact-Checker, and Synthesizer/Router.
  • Integrated MCP tools for external fact-checking and added controlled retry and routing logic to handle uncertain answers.
  • Built a Gradio interface with live knowledge ingestion and page-level source highlighting.
  • Exposed the RAG pipeline through FastAPI, Flask, and MCP, and integrated it with a WhatsApp interface.
  • Developed an analytics dashboard to monitor query volume, topics, answer quality, and API costs.

Data Science in Production · EPITA 2026

Energy Production Forecasting - MLOps Platform

Developed an end-to-end MLOps platform for renewable energy production forecasting, covering the full machine learning lifecycle from data ingestion and quality validation to automated prediction, model training, deployment, and production monitoring.

The platform uses Apache Airflow to orchestrate data and prediction workflows. Predictions are generated automatically on a scheduled basis and whenever newly ingested data becomes available. Incoming data is validated with Great Expectations, with data-quality issues stored in PostgreSQL and reported through Microsoft Teams. A Streamlit interface connects to a FastAPI model-serving API for on-demand and historical predictions.

Key Contributions

  • Built automated data ingestion and prediction pipelines with Apache Airflow, including scheduled predictions and automatic prediction runs when new data is ingested.
  • Implemented data quality validation with Great Expectations and stored validation results and issues in PostgreSQL.
  • Developed model training and versioning workflows with MLflow and the MLflow Model Registry.
  • Implemented automatic model retraining when data drift is detected.
  • Built a FastAPI model-serving API and Streamlit interface for on-demand and historical energy production predictions.
  • Implemented production monitoring with daily data-drift detection and Grafana dashboards covering data quality, prediction performance, training metrics, and system health.
  • Containerized the complete platform using Docker Compose.
  • Set up CI/CD with GitHub Actions, including automated testing, linting, versioning, and release workflows.

Applied Research + Product · EPITA 2026

Bird Sound Classification & NaturePulse

AI-powered biodiversity monitoring

Combines an academic study on robust bird sound classification with NaturePulse, a practical collaborative biodiversity monitoring platform built from the research.

Research

Investigated bird sound classification on the BirdCLEF+ 2026 dataset, focusing on domain shift, class imbalance, and environmental noise in real-world soundscapes (three-person team).

Evaluated EfficientNet-B0, -B3, and EfficientNetV2-S on Mel spectrograms, then explored semi-supervised pseudo-labeling for soundscape adaptation and an augmentation ablation study (SpecAugment, MixUp, Random Filtering). EfficientNet-B0 gave the most consistent leaderboard performance and was selected for pseudo-labeling; augmentation improved F1-score while keeping ROC-AUC stable.

NaturePulse platform

  • AI-assisted species identification from uploaded wildlife audio
  • Community observations with photos, audio, location, and time
  • Specialist & community review to validate observations
  • Searchable species browser with an interactive map
  • AI chatbot for species Q&A
  • Sound-ID quizzes and community leaderboards
  • Research-ready biodiversity data with export

Impact: reduces the time and effort to analyse wildlife recordings while improving the reliability of biodiversity observations through community and specialist validation - a practical foundation for collaborative biodiversity monitoring and ecological research.
