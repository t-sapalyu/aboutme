# Thin Sapal Yu - Portfolio

Personal portfolio site for **Thin Sapal Yu**, Software Engineer / AI & Data Engineer (internship from Oct 2026).

🔗 **Live site:** https://t-sapalyu.github.io/aboutme/

## About
Single-page, responsive portfolio built as plain HTML/CSS (no build step) and hosted on GitHub Pages.
Content is sourced from my CV and covers: profile, skills, work experience, academic and cloud projects,
education, patents, and languages. Includes a light/dark theme toggle.

## Structure
```
index.html                        # the portfolio page
assets/profile.png                # profile photo
assets/Thin-Sapal-Yu-CV.docx      # downloadable CV (English)
assets/Thin-Sapal-Yu-CV-FR.docx   # downloadable CV (French)
```

## Editing
Everything lives in `index.html` - edit the relevant section and commit. Changes go live within a
minute or two of pushing to `main`.
